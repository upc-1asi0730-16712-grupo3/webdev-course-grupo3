# Fundamentos de Desarrollo Web con HTML y CSS

## Resumen del Curso

Este curso de 1 hora introduce a estudiantes de secundaria a la creación de sitios web sencillos utilizando HTML y CSS. **¡No requiere descargas!** Solo necesitas tu navegador web.

- **Duración total**: ~60 minutos
- **Público objetivo**: Estudiantes de 12 a 17 años sin experiencia previa en programación
- **Prerrequisitos**: Ninguno
- **Herramientas necesarias**: **¡Solo tu navegador web!** (Chrome, Firefox, Safari, Edge)
- **Repositorio de Código Fuente**: [https://github.com/upc-1asi0730-16712-grupo3/webdev-course-grupo3](https://github.com/upc-1asi0730-16712-grupo3/webdev-course-grupo3)

## Secuencia de la Lección

### Lección 1 y 2: Introducción al desarrollo web y Estructura HTML básica
- **Descripción**: Aprende de qué están hechos los sitios web, por qué HTML y CSS son sus componentes fundamentales y explora la estructura interna mediante etiquetas, elementos y atributos básicos.
- **Enlace**: [▶ Ver la lección](https://youtu.be/MvML7szGxy8?si=bQhv8ZY6_-holaW6)
- **Conclusiones clave**: Un sitio web combina Contenido (HTML) y Estilo (CSS). Las etiquetas organizan el texto y definen la jerarquía básica de una página.
- **Práctica**: [🖥 Abrir en editor que usase](https://codepen.io/editor/pen) 
- **Código fuente**: [Ver en GitHub](https://github.com/upc-1asi0730-16712-grupo3/webdev-course-grupo3/tree/main/starter-files/completed-examples/scripts/leccion%201)
### Lección 3: Elementos HTML comunes 
- **Descripción**: Aprende a enriquecer el contenido de tu página agregando encabezados, párrafos, listas ordenadas y no ordenadas, imágenes y enlaces interactivos.
- **Enlace**: [▶ Ver la lección]( )
- **Conclusiones clave**: Se usan las etiquetas `<ul>`, `<ol>`, `<li>`, `<img>` (con su atributo `alt`) y `<a>` para conectar tu web con otros sitios.
- **Práctica**: [🖥 Clic para programar editor que usase]( )
- **Código fuente**: [Ver en GitHub]( )

### Lección 4: Introducción a CSS
- **Descripción**: Descubre cómo darle personalidad y estilo a tu estructura HTML utilizando selectores y propiedades fundamentales como colores de fondo, fuentes y estilos de texto.
- **Enlace**: [▶ Ver la lección]( )
- **Conclusiones clave**: Conecta archivos CSS a tu HTML. Utiliza selectores de etiquetas y clases, y aplica propiedades como `color`, `background-color` y `font-family`.
- **Práctica**: [🖥 Aplicar estilo en editor que usase]()
- **Código fuente**: [Ver en GitHub]( )

### Lección 5: Estilo simple y diseño 
- **Descripción**: Ajusta el diseño visual de tus elementos aprendiendo a centrar contenido, agregar bordes decorativos y aplicar márgenes y rellenos.
- **Enlace**: [▶ Ver la lección]( )
- **Conclusiones clave**: Entiende el modelo de caja (Box Model), cómo usar `margin: 0 auto`, `padding`, `border-radius` y centrar textos con `text-align: center`.
- **Práctica**: [🖥 Practicar diseño editor que usase]( )

### Lección 6: Creación de una página web básica (Perfil Personal) 
- **Descripción**: Consolida todo lo aprendido combinando HTML y CSS para construir tu primer proyecto completo: una página de perfil personal o entrada de blog.
- **Enlace**: [▶ Ver la lección](https://youtu.be/zoEc-7y3UUE)
- **Conclusiones clave**: Aplica etiquetas semánticas (`<header>`, `<main>`, `<section>`, `<footer>`), añade estilos CSS organizados y depura errores visuales.
- **Proyecto final**: [🖥 Crea tu Perfil en Replit](https://replit.com/) **¡Guarda y comparte tu trabajo!**
- **Código fuente**: [Ver en GitHub](https://github.com/upc-1asi0730-16712-grupo3/webdev-course-grupo3/tree/main/starter-files/completed-examples/scripts/Leccion6)

### Lección 7: Recomendaciones y errores comunes para principiantes
- **Descripción**: Conoce los errores más frecuentes que cometen los principiantes al programar, cómo depurar código de forma sencilla y recomendaciones para seguir aprendiendo.
- **Enlace**: [▶ Ver la lección]( https://youtu.be/yCLJ0CxGGpM )
- **Conclusiones clave**: Recuerda cerrar siempre las etiquetas, documentar con comentarios tu código y seguir intentadolo!
- **Código fuente**: [Ver en GitHub](https://github.com/upc-1asi0730-16712-grupo3/webdev-course-grupo3/tree/main/starter-files/completed-examples/scripts/Leccion7)
